Spintron measurements make valve motion visible. I compare a clean, low-speed Spintron lift measurement with a fitted OpenModelica model in VTsim, looking at the whole event, including closing and seating, not just peak lift.

This is a dated, fitted development case from September 2026. It is not the current production model and not a validated operating envelope. Both traces use the same cam-referenced alignment and the same lift normalization. The traces were not shifted independently to improve agreement.

A spring model that follows the test

Measured force versus height is the starting point for spring fitting. Body rate, the approach to coil bind and model residuals are checked separately; the tester’s post-bind stiffness is not treated as spring stiffness.

The spring workflow also creates helix geometry in FreeCAD. The model and CAD need to describe the same spring, not just share a label.

Engine Pressure Measurement & Simulation

Pressure data is a constraint,
not decoration.

Single-cylinder work in progress

I use AVL IndiCom cylinder pressure measurements and indicating analysis to examine combustion and gas exchange, and to guide development of Wind Section / IC-core.

IC-core is a wide-open-throttle, one-dimensional engine cycle model with gas dynamics, thermodynamics, heat transfer and measured valve-lift input. The work is being extended from a single-cylinder structure to multiple cylinders.

This is not a correlation claim.

The plot is an archived, early single-cylinder model snapshot beside measured pressure. The disagreement is part of the development work. Multi-cylinder extension and correlation remain under way.

Both traces use a common pressure reference and a common volume reference before plotting on logarithmic axes. Units, absolute scale, tick values and operating conditions are fully masked. No raw data is included.

CamProfileDesignStudio

Design motion first.
Then the lobe.

Synthetic example

CamProfileDesignStudio works in the valve-motion domain, using a multi-polynomial cam profile method. Lift, velocity and acceleration are considered together before kinematic transforms produce tappet motion and cam geometry.

The broader workflow supports profile diagnostics, rocker kinematics and pitch-radius output for cam grinding. It is a design tool, not a substitute for dynamic testing.

Port Flow CAD

A prompt-and-image-guided FreeCAD workflow turns an intake-port concept into a solid fluid domain for meshing. The render shows an idealized parametric port, not a scanned internal passage.

Cd study: CFD back into the cycle model

Generic pipe-mouth cases in OpenFOAM examine how inlet lip radius and pressure ratio affect discharge coefficient. The resulting Cd surface supplies boundary conditions to the one-dimensional model.

Checks include station definitions, mass-flow accounting and predictions at new CFD cases. I use both interpolation residuals and held-out checks; passing through the known points alone is not validation.

The trend below uses generic geometry, not a customer port. The second panel compares spline predictions made before new CFD cases were run with the values those cases produced. Axes are masked. It is not a trend of measured engine flow or power.

How I work with AI

I direct teams of AI coding agents to build and validate engineering software at a pace a small shop normally could not.

I own the physics, test data, acceptance checks and engineering judgment. Agents help implement and test the tools. Agreement with a test, a reference case or a conservation check has to be demonstrated, not asserted.
